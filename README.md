# Japanese Cinema

A `three.js` project where you can watch trailers of the movies that was currently on air in Japan at the time of creation of the project.

## Installation

### Docker

> [!NOTE]
> The project is not yet dockerized.

### Manual

```bash
git clone https://github.com/joshika39/japanese-cinema.git

cd ./japanese-cinema/node-js/

npm install

# Go to http://localhost:3000 after running the following command
node app.js
```

## Usage

### Controls

| Key     | Description                          |
| ------- | ------------------------------------ |
| `W`     | Move forward                         |
| `A`     | Move left                            |
| `S`     | Move backward                        |
| `D`     | Move right                           |
| `Space` | Jump                                 |
| `R`     | Open the movie trailer selector menu |
| `Q`     | Move selector to the left            |
| `E`     | Move selector to the right           |
| `Enter` | Play the selected movie trailer      |
| `Ctrl`  | Toggle sit/stand                     |
